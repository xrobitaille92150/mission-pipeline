# Rappel des priorités de Xavier pour la notation

- Clusters B (investissement, plateformes, investment accounting) et C (transformation finance, PMO, programme) d'abord ; cluster A (actuariat, passif) en second ; le reste hors axe.
- France en hybride est la cible. Royaume-Uni, Irlande, Benelux, Suisse : acceptables, second rang. Full remote : second rang. Hors Europe : éliminatoire.
- Mission ou freelance autour de 1 000 € par jour est le format recherché ; un CDI en France reste envisageable pour un poste d'intérêt ; un CDI hors France ne l'est pas.
- Le niveau attendu est senior manager / director / directeur de programme. Un grade « 8-10 ans » pour un profil de 25 ans est un décalage, pas un plus.
- Les signaux forts : SimCorp Dimension, Clearwater, IFRS 17, Solvabilité II, IFRS 9, SAP, assureur ou réassureur ou asset manager comme employeur final.
